💡 壓秒集結計算原理說明

📐 計算公式：
【發起集結時間】=【目標到達時間】−【行軍時間】−【集結等待時間】
【集結出發時間】=【發起集結時間】+【集結等待時間】=【目標到達時間】−【行軍時間】

🎯 什麼是壓秒集結？

在 Kingshot 的據點戰中，防守方通常會有駐軍支援。透過同步多個集結的撞擊時間（例如前後差在 1~2 秒內），可連續打擊目標，不給敵方補兵與治療的時間，達到最大化傷亡效果。

⏰ 行軍時間如何取得？

隊長點擊目標據點，按下「攻擊」或「集結」預覽畫面，即可查看該隊伍單程行軍時間（幾分幾秒）。請隊長提供不開加速狀態下的時間，並確認行軍過程中不要誤點加速。

⏰ 如何快速同步時間？

點擊「重設為目前時間」即可將目標時間對齊目前 UTC 伺服器時間，再搭配快捷微調按鈕或上下箭頭，即可在數秒內迅速定案撞擊時間。

🌐 如何放到 GitHub Pages？

本工具為純靜態網頁（HTML/CSS/JS），只需將專案推送至 GitHub Repository，在倉庫的 Settings > Pages 中將 Source 設定為 main 分支根目錄即可免伺服器永久免費運行。
